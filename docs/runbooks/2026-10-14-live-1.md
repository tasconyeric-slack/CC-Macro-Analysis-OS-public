**1.3 Credential and first genuine run (strongly recommended on 10-11 to 10-12).** The Copilot needs `DEEPSEEK_API_KEY` in the local shell that runs it. Enter it interactively; never put it in a committed file, command argument, or transcript. It is not needed for refresh, context-only replay, tests, the static site or a manual update.

```powershell
# Windows PowerShell, from the repository root after pip install -e ".[dev]"
$secureKey = Read-Host "DeepSeek API key" -AsSecureString
$keyPtr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secureKey)
try { $env:DEEPSEEK_API_KEY = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($keyPtr) }
finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($keyPtr) }
python -m cnmacro copilot preflight --release "September 2026 CPI and PPI"
$replay = python -m cnmacro copilot replay --release-at 2026-08-09 --out site/replay/copilot | ConvertFrom-Json
$replayExit = $LASTEXITCODE  # 0 validated | 2 failed validation | 3 model unavailable | 4 no context
$replay
$replayExit
python -m cnmacro copilot runs
if ($replay.run_id) { python -m cnmacro copilot verify --run-id $replay.run_id }
Remove-Item Env:DEEPSEEK_API_KEY
if ($replay.run_id) {
    git add "research/cases/cn-nominal/copilot/runs/$($replay.run_id)"
    git commit -m "copilot: DeepSeek replay $($replay.run_id)"
    git push origin HEAD
}
```

This is the first **genuine** end-to-end proof (G-A, replay half) and a rehearsal of the release-day code path. It is exploratory (`eval_eligible: false`: no human labels exist yet); never quote it as a model-performance result. The default is `deepseek-flash`; explicitly choose `--model deepseek-v4-pro` or set `CNMACRO_COPILOT_MODEL=deepseek-v4-pro` to override it. The transport uses DeepSeek's [Anthropic-compatible Messages API](https://api-docs.deepseek.com/guides/anthropic_api/) at `/anthropic/v1/messages`, with `output_config.effort` and no added SDK. Calls are not streamed and each pass is capped at 24,000 output tokens by default. A timeout, refusal or truncation is recorded as an unavailable run, without automatic retry. The Run Record stores reported tokens and latency; cost is unknown until valid DeepSeek billing information is available. Set `--knowledge-cutoff` only when the chosen model's published cutoff is known.

The repository is private (verified 2026-10-10), so committing a Run Record, which contains unapproved AI output, does not publish it; the site never reads it. Commit every genuine Run Record, including failed calls and validation failures. Do not rerun until you like the answer: every run is evidence, including the bad ones.

If there is no refresh commit by about 11:30 CST (the cron can lag, or a source was unreachable): trigger the workflow *public data refresh* (Actions → Run workflow, leave both boxes off), or run it yourself:

Partial data (CPI in, PPI not yet) is normal: the refresh is idempotent; run it again later. Exit code 1 means the eval gate failed and nothing was committed: run `python -m cnmacro check --public` and read the failing check. The Copilot waits for this step and nothing else waits for the Copilot.

**2.3 Look at the facts, not the AI.** The delta is deterministic and free:

```bash
python -m cnmacro copilot context --release "September 2026 CPI and PPI"
```

Expect `new_observations` to list six `obs:...@2026-09` refs, the per-hypothesis `mechanical_delta`, and `expectation: frozen`. Exit 4 `no_context` means the release is not in the store yet: go back to 2.2. Nothing was sent to a model.

**2.4 Run the Copilot (shadow).** It prints status and cost, never content:

```bash
python -m cnmacro copilot run --release "September 2026 CPI and PPI"
```

| Exit | Meaning | Do |
|---|---|---|
| 0 | validated, record written | continue at 2.5 |
| 2 | a hard gate failed; the record shows which | the output is blocked and cannot be shown; you may run again (each run is kept; do not cherry-pick); otherwise continue manually |
| 3 | `copilot: unavailable` (no key, outage, refusal, truncation); record written | continue manually; write `copilot: unavailable` in your update |
| 4 | no delta | the refresh has not ingested the release (2.2) |

**2.5 Blind take (at most 5 minutes) BEFORE you read the Copilot** (strategy §11.4; this is what lets us measure what the AI added):

```bash
python -m cnmacro copilot blind-take --run-id <RUN_ID> --author <you> \
  --text "1) most important change: ...  2) hypothesis it touches: ...  3) direction: ..."
git add research/cases/cn-nominal/copilot/runs/<RUN_ID> && git commit -m "copilot: blind take for <RUN_ID>" && git push origin main
```

Push at once: the commit time is the evidence that your take preceded the AI read. `show` refuses until a blind take exists (a waiver, `--waive-blind-take "reason"`, is recorded and excludes the run from the marginal-insight measure).

**2.6 Read, then decide.**

```bash
python -m cnmacro copilot show --run-id <RUN_ID>         # What changed, Divergence, Why it matters, Counter-case, What we still don't know, Draft update
python -m cnmacro copilot decide --run-id <RUN_ID> --template > /tmp/decision.yaml
$EDITOR /tmp/decision.yaml                               # per section: accept | edit | reject | keep_unresolved, a reason, final_text for edits;
                                                         # per divergence: accept | reject | keep_unresolved; thesis_decision: unchanged | changed
python -m cnmacro copilot decide --run-id <RUN_ID> --file /tmp/decision.yaml
```

The decision is stored with a diff of every edit. It does **not** change the thesis. The AI has no write path to your update, the baseline, the claims or the site.

## 5. Failure handling at a glance

| Situation | The pipeline | You |
|---|---|---|
| Official source unreachable at 10:20 | the refresh records the failed source and retries at 18:20 | rerun 2.2 manually if you cannot wait; the update clock is 48 h |
| Refresh commit never appears | nothing is lost; data is append-only | run it locally (2.2) |
| Eval gate fails during the refresh | nothing is committed | `python -m cnmacro check --public`; fix; rerun |
| No API key / outage / refusal | unaffected | continue at section 3; write `copilot: unavailable` |
| Gate failure (exit 2) | unaffected | continue manually; the failed record is a data point (do not delete it) |
| You forgot the blind take | unaffected | `--waive-blind-take "reason"`; recorded as not blind |
| Expectation Note missed | unaffected | publish without it; do not backfill |
| Replay or model behaves oddly | unaffected | the Copilot is shadow; nothing it produces is public |
