# CtaStrip

A rare full-width dark band with a headline on the left and one red CTA on the right.

- Class `mr-cta-strip`: `surface-dark` fill, `on-dark` text, padding 48px 32px, `radius-none` (it is a structural band).
- Title `heading-xl`; optional subline in `body-md` `on-dark-mute`.
- Exactly one `mr-btn--primary`. Use at most once per page, typically on creator / business pages.
