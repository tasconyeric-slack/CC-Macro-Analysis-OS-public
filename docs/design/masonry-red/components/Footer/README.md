# Footer

A quiet 4-column link grid under a hairline top rule.

- Class `mr-footer`: `canvas` fill, `mute` text in `body-sm`, padding 32px 24px, 1px `hairline` top rule, `radius-none`.
- Column headers `mr-footer__h` in `body-sm-strong` `ink`; links in `mute`.
- Base row: brand in `primary` plus "© year" in `caption-sm` `mute`.
- 4 columns at desktop, 2 at tablet, an accordion at mobile (each header becomes a tap-to-expand row).
