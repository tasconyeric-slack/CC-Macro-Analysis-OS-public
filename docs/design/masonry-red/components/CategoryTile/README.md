# CategoryTile

A cream tile pairing a square thumbnail with a short category label, shown 3 or 4 across.

- Class `mr-tile`: `surface-card` fill, padding `space-lg`, `radius-md`, label in `body-strong` `ink`.
- Thumbnail `mr-tile__thumb`: always 1:1 with `radius-md` corners.
- A thumbnail may carry one overlay pill (`mr-pill`) naming a search term: the system's signature decorative gesture.
- Grid: 4-up desktop, 3-up desktop-small, 2-up mobile, `space-lg` gaps.
