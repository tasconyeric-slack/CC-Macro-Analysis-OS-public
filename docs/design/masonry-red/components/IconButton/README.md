# IconButton

A 40px circular icon control for carousel paddles, modal close and small floating actions.

- Class `mr-icon-btn`: `surface-card` fill, `ink` glyph, `radius-full`, `size-icon-button` (40px).
- Glyph: an inline SVG at 20px, `fill: currentColor`.
- Pressed: fill goes to `secondary-bg`.
- On photography use `mr-icon-btn--on-image` (`canvas` fill) so it reads against any image.
- Pad the hit area to 48×48 in the parent; the visible circle stays 40px.
- Always give it an `aria-label`.
