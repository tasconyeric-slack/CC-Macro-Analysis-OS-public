# FilterChip

A pill toggle for the filter strip above search results; it inverts fully when active.

- Class `mr-chip` with `aria-pressed`.
- Default: `surface-card` fill, `ink` text, `button-md`, padding 8px 16px, `radius-full`.
- Active (`aria-pressed="true"` or `.is-active`): `ink` fill, `on-dark` text.
- Chips sit in a single horizontally scrolling row, `space-md` apart.
- Labels are search refinements, written in sentence case.
